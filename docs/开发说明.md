# 开发说明

> 面向维护 / 二次开发的技术文档。**使用方法请看根目录的 [README.md（使用手册）](../README.md)。**

按《[技术需求书-股票App.md](../技术需求书-股票App.md)》v0.3 实现。

**定位**：A 股 / 美股，日线，趋势波段（3~20 个交易日）的选股、验证与持仓管理工具。两个市场的数据、参数、回测各自独立。

**技术栈**：

- **前端**：原生 HTML / CSS / JS，零框架、零构建，可装成 PWA。
- **后端**：本地 Python，FastAPI + SQLite + pandas。

## 1. 开发环境

```bash
pip install -r server/requirements.txt      # Python 3.10+
python -m server.cli serve --demo           # 合成演示数据（不代表真实行情）
python -m server.main                       # 真实数据，http://127.0.0.1:8000（PORT 环境变量可改端口）
python -m pytest -q                         # 单元测试（130+ 条，离线，只用演示数据）
```

**常用命令行**（`python -m server.cli --help`）：

| 命令 | 作用 |
| -- | -- |
| `init` | 首次初始化：全量下载 |
| `init --random 100` | 首次初始化：只随机下载 100 只 |
| `update` | 盘后任务链 |
| `scan` | 选股扫描 |
| `backtest --kind K` | 回测与检验 |
| `backup` / `restore` | 备份与恢复 |
| `l1-bias` | L1 入库偏差实验 |

**环境变量**：

- `STOCK_DATA_DIR`：指定数据目录。
- `STOCK_CONFIG`：指定配置文件。
- `PORT`：指定端口。

测试和预览请用独立端口和配置副本，并关闭调度与预热（`jobs.scan_on_startup: false`、`jobs.prewarm: false`）。

## 4. M0 实测中发现、并已在代码里处理的事项

- **baostock 0.9.4 与 pandas ≥ 2 不兼容**：`get_data()` 调用了已删除的 `DataFrame.append`。处理：改为逐行组装 DataFrame。
- **`query_all_stock` 单次约 15~20 秒**：处理：名单并集半年取样，并记录进度。
- **BaoStock 10 年历史单只约 8~10 秒**：
  - 先用快照或近 45 天数据预筛，只对通过的股票拉 10 年历史。
  - 初始化时每只只发 2 次请求（日线 + 复权因子）。
  - 每日增量每只只发 1 次请求。
- **yfinance 价格已按拆股调整**：处理：必须存拆股事件，价格门槛用「还原后的当时价」；拆股后整只重拉。
- **Yahoo 新闻接口**：`Ticker.news` 在本机返回空，改用 `Search(...).news`。
- **BaoStock 单位**：`volume` 是「股」、`amount` 是「元」；复权因子用 `backAdjustFactor`。
- **停牌日**：BaoStock 仍返回一行（`tradeStatus=0`），系统不填充价格。

## 5. 回测校准结论（决定了当前默认值）

**数据与方法**：

- A 股 2016~2026 日线。
- 前 60% 的历史用来挑参数（样本内），后 40% 用来检验（样本外）。
- 个股部分用 3 组、各 1200 只随机股票，含已退市股票。
- 用 `tools/calibrate.py`、`tools/risk_sizing.py` 可以复现。

**结论**：

| 主题 | 结论与默认值 |
| -- | -- |
| 市场温度 | 市场级信号是逆向的：全 A 站上 20 日线比例 < 15% 之后上涨概率最高，> 80% 之后最差。「趋势强就加仓」的复合评分没有预测力，不采用 |
| 宽基 ETF 规则 | 50% 趋势仓（MA20 ±2% 滞回）+ 50% 抄底仓（冰点买入、3×ATR 止损、过热或 40 天离场）。样本外年化 7.2%、最大回撤 -15%；一直持有为 4.2%、-34% |
| 指数抄底仓固定止盈 | +5% / +8% / +10% / +3ATR / +5ATR 在样本内都劣于不止盈。规则不设，只显示参考位 |
| 个股形态 | 「突破」「回踩」显著差于同日随机入场（t ≈ -4 ~ -7）。「强势超跌」在完整成交规则下样本外为负。默认只启用「波动收缩突破」（样本内外都为正，但不显著） |
| 市场环境闸门（个股） | 保留：关掉后明显变差 |
| 高开处理 | 「高开就放弃」无稳定好处，关闭；「按开盘价重算股数，只少不多」：回撤更小、收益基本不变，开启 |
| 个股止盈 | 7 种方式里「+10% 全部卖出」样本内最好，样本外 3 组都优于只用移动止损，开启 |
| 每笔最多亏 | 10 万资金下 0.75% 收益风险比最好；更小会被整手和最低佣金拖累，更大回撤大且常资金不足 |
| 回撤后降风险 | 多数样本只降低收益、不降低回撤，不采用 |
| 资金方案（v0.7.0 起） | 10 万资金、2018~2026：ETF 70% + 低风险组合 30% 全程年化 5.1% / 回撤 -12.5% / Sharpe 0.70（样本外 9.0%）；v0.6 的 ETF 70% + 个股波段 2 只为 4.0% / -11.0% / 0.63（样本内 3.7% 更好、样本外 4.5% 差很多）。ETF 30%~70% 之间 Sharpe 几乎一样，取回撤最小的 70%。加入个股波段（1 或 2 只）各时段都没有更好，默认不分钱。ETF 与组合日收益相关性 0.35 |
| 关键均线（v0.8.0） | 长历史（创业板 2011~、标普 1951~、纳指 1986~，美股含股息、空仓拿国债利息），每条均线 ± 2% 滞回两种，事先定好「两段都 Sharpe ≥ 一直持有、最大回撤浅 10 个百分点以上」才算可操作。标普：200 / 250 日可操作，短均线全部不行，主线 200 日（10.4% / -22%，持有 10.8% / -55%）；纳指：只有 200 日（12.8% / -59%，持有 15.2% / -83%）；创业板：20 日 ±2%（13.8% / -45%）、60 日 ±2%、250 日可操作。距年线 -20% 以下：标普之后 120 日平均 +14.9%、上涨 85%（27 次），纳指 +1.5%、50%（不抄底）。杠杆版本回撤 -70% ~ -95%，不给建议 |
| 低风险组合（v0.7.0） | 全市场 5133 只、2018~2026，事先写好 8 个方案（综合分 2 种 × 10/20 只 × 每 10/20 天），100 万资金：「低换手 + 低波动」样本内年化 -1%~+1%（交易池等权 -5.1%、沪深300 -1.1%、中证500 -1.5%），回撤约 -22%（等权 -43%）；样本外 +16%~+23%，回撤 -9%~-13%，Sharpe 1.27~1.66。加「短期反转」：换手 17~30 倍、样本内 -2%~-6%，否决。检查：打分推迟一天结果不变（无未来函数）；随机打分 ≈ 等权（引擎无偏）。按真实资金（4~5 万）重选 10/20 只 × 每 10/20 天：样本内差别在噪音内，取手续费低、好操作的 10 只、每 20 个交易日。「一手买不起就让给下一名」样本内完全一样、样本外小资金 +0.3~0.6%/年，采用。分年度：2018 -10%、2020 -10%（沪深300 +27%）、2023 +17%、2024 +42%、2025 +3%（沪深300 +18%）——强烈依赖风格，熊市少亏、小盘 / 题材牛市大幅跑输 |
| 宽基轮动（2026-10-10） | 趋势仓只做近 20 日涨幅前 2 的指数：组合样本内 Sharpe 0.40→0.57、样本外 0.71→0.79，回撤都更小。「按波动率减仓」「按 1/ATR 分配」样本内更差，不采用 |
| 宽基参数敏感度 | 一次动一个参数，样本外 Sharpe 0.68~0.92（持有 0.31），是平台不是尖峰，不再微调。分年度：熊市少亏很多、牛市明显跑输 |
| 策略健康度 | 当前回撤与 10 年回测最大回撤（-12.8%）比较：≥ 六成为「注意」，超过为「警告」（暂停新开仓、复查） |
| 候选排序 | 横截面 Rank IC（2 组抽样、样本内外一致）：RPS、行业强弱、换手率、波动率都为负 → 默认改为「低换手 + 低波动」（`funnel.score_method: lowrisk`）。完整策略内只影响少数交易，前后两段结论不一致，效果小 |

**局限**：结论来自同一段历史，检验次数会累积运气成分；个股结论来自抽样，不是全市场（低风险组合用的是全市场）。

**低风险组合的实现要点**（`server/factor_portfolio.py`）：

- 回测与实盘同一套规则：T 日收盘打分出名单、T+1 开盘成交；涨停开盘买不进就放弃、跌停开盘卖不出顺延；整手、最低 5 元佣金、印花税、过户费、滑点。
- 调仓日历从 `factor_portfolio.anchor`（2018-01-02）起每 `rebalance_days` 个交易日一次，所有人同一套日期；选股页的回测证据按这个日历对齐，期末持仓与今天的名单可以直接对照。
- 今天的名单直接用选股的全市场面板（`main._scan_ctx`），不额外加载；回测证据（全市场 8 年，约 1.5 GB、1~2 分钟）在盘后任务链 / 启动预热时后台算一次，存 `data/cache/factor_bt_CN.json`，数据日、参数或分给组合的资金变了才重算。
- 「组合」持仓用 `positions.setup = 'factor'` 标记：体检只估值，不做止损 / 止盈 / 时间退出，不占个股波段的风险额度和空位。

## 6. 默认假设（均可在 config.yaml 或设置页修改）

- **费率**（2026-10 核对现行规则）：
  - 印花税 0.05%，仅卖出收；
  - 过户费 0.001%，买卖双向收；
  - 佣金按万 2.5 设定，最低 5 元。
- **备份**：
  - 每日备份个人库和不可重建的数据，写入 `data/user_config.yaml` 里 `backup.dir` 指定的目录。
  - 行情库全量备份每周一份，gzip 压缩，只留最新 1 份（`backup.keep_full`）。
- **检验通过标准**（`config.yaml` 的 `validation`）：
  - 单因子：至少 2 个周期同时满足 |IC| ≥ 0.02、|IR| ≥ 0.3、有效 t ≥ 2、分层单调性 ≥ 0.8，且方向一致。
  - 形态：独立信号日 ≥ 50、p ≤ 0.05（对随机入场基线）、按日期望 R > 0、95% 置信区间下限 > 0、正期望年份占比 ≥ 60%。
- **财报日历**：用 BaoStock `query_profit_data` 的实际披露日，按去年同期推算今年预计披露日。
